# Scripts Python : Recueil d'Exemples

Lien vers le cours : [Introduction au langage Python 2.7 par l'exemple (2012)](https://stahe.github.io/python2.7-mars-2012/)

---

## 📌 Présentation

Ce projet propose une collection de scripts Python couvrant divers domaines techniques. Il ne s'agit pas d'un cours théorique, mais d'un **recueil d'exemples** concrets destinés à une initiation rapide.

### Domaines abordés :

**Fondamentaux** du langage Python.

* Gestion de bases de données **MySQL**.

* Programmation réseau TCP/IP

* Programmation **Web**.

* Architectures **trois couches** et programmation par **interfaces**.

---

## 🎯 Public visé

Ce document est conçu pour des développeurs ayant déjà une expérience avec:

* Des langages de script (**Perl, PHP, Vbscript**).
* Des langages typés (**Java, C#**) et souhaitant découvrir l'orienté objet en Python.

> [!IMPORTANT]
> Ce contenu est **inapproprié** pour les débutants complets en programmation. Il n'a pas pour vocation d'enseigner les "bonnes pratiques" absolues ; un développeur expérimenté pourra juger que certains codes mériteraient d'être optimisés.
> 
> 

---

## 📖 Comment utiliser ce recueil

Pour tirer profit de ce dépôt, une **lecture active** est indispensable. Pour chaque script, vous trouverez :

* Le code source commenté.


* La reproduction de l'exécution en console.


* Des explications complémentaires si nécessaire.
